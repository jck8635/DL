# 문장 유해 표현 및 피싱·광고 탐지 프로젝트

## 1. 프로젝트 소개

이 프로젝트는 사용자가 입력한 문장을 분석하여 **정상 문장, 유해 표현, 피싱·광고 문장**을 구분하는 텍스트 탐지 프로그램입니다.

하나의 모델로 모든 유형을 탐지하는 대신, 탐지 목적에 따라 두 개의 CNN 모델을 사용합니다.

- **Char-CNN:** 문자 단위로 문장을 분석하여 유해 표현을 탐지합니다.
- **TextCNN:** 단어 단위로 문장을 분석하여 피싱 및 광고 문장을 탐지합니다.

두 모델의 예측 결과를 조합하여 최종적으로 네 가지 결과를 제공합니다.

1. 정상
2. 유해 표현
3. 피싱·광고
4. 유해 표현 + 피싱·광고

프로젝트는 Python과 PyTorch를 이용해 모델을 학습하고, Streamlit을 이용해 사용자가 직접 문장을 입력하고 결과를 확인할 수 있도록 구현했습니다.

## 4. 프로젝트 파일 구성

프로젝트는 크게 모델 학습 파일과 웹 애플리케이션 파일로 구성됩니다.

```text
project/
│
├── train.ipynb
│   └── 데이터 전처리 및 모델 학습
│
├── app.py
│   └── 학습된 모델을 이용한 문장 탐지 웹 애플리케이션
│
├── dataset/
│   ├── dataset1.csv
│   ├── dataset2.csv
│   ├── dataset3.csv
│   └── dataset4.csv
│
└── models/
    ├── char_cnn_best.pt
    ├── text_cnn_best.pt
    ├── char_vocab.pkl
    ├── word_vocab.pkl
    └── model_config.pkl
```

※ 위 폴더 구조는 이해를 돕기 위한 예시입니다. 실제 데이터 파일명과 저장 폴더는 프로젝트 환경에 맞게 확인해야 합니다.

### 주요 파일 설명

- `train.ipynb`: CSV 데이터를 정리하고 Char-CNN과 TextCNN을 학습하는 Jupyter Notebook입니다.
- `app.py`: 학습된 모델을 불러와 사용자의 입력 문장을 분석하는 Streamlit 프로그램입니다.
- `char_cnn_best.pt`: 학습된 Char-CNN 모델의 가중치입니다.
- `text_cnn_best.pt`: 학습된 TextCNN 모델의 가중치입니다.
- `char_vocab.pkl`: Char-CNN에서 사용하는 문자 어휘 사전입니다.
- `word_vocab.pkl`: TextCNN에서 사용하는 단어 어휘 사전입니다.
- `model_config.pkl`: 모델의 최대 입력 길이 등 설정 정보를 저장한 파일입니다.

## 5. 데이터 전처리

여러 CSV 데이터셋을 사용하며, 데이터셋마다 다른 문장 컬럼명과 라벨을 통일하는 작업을 진행합니다.

주요 전처리 과정은 다음과 같습니다.

1. CSV 파일 불러오기
2. 문장 및 라벨 컬럼명 통일
3. 데이터셋별 라벨 기준 통일
4. 빈 문장 및 잘못된 데이터 제거
5. 동일 문장의 라벨 충돌 확인 및 제거
6. 중복 데이터 제거
7. 모델별 학습 데이터 구성

### 모델별 라벨 구성

| 모델 | 라벨 0 | 라벨 1 |
|---|---|---|
| Char-CNN | 정상 | 유해 표현 |
| TextCNN | 정상 | 피싱·광고 |

원본 데이터의 라벨을 모델별 이진 분류 기준에 맞게 변환하여 학습에 사용합니다.

## 6. 모델 설명

### 6-1. Char-CNN

Char-CNN은 문장을 문자 단위로 분리하여 분석하는 CNN 모델입니다.

예를 들어 `안녕하세요`라는 문장이 입력되면 다음과 같이 처리합니다.

```text
안녕하세요
    ↓
안 / 녕 / 하 / 세 / 요
    ↓
문자 ID 변환
    ↓
Embedding
    ↓
CNN 특징 추출
    ↓
정상 또는 유해 표현 분류
```

문자 조합을 중심으로 특징을 학습하기 때문에 문자 형태가 중요한 유해 표현 탐지에 사용합니다.

### 6-2. TextCNN

TextCNN은 문장을 단어 단위로 분리하여 분석하는 CNN 모델입니다.

예를 들어 다음 문장이 입력되면,

```text
지금 바로 이벤트에 참여하세요!
```

단어와 숫자, 기호 등을 분리하여 처리합니다.

```text
지금 / 바로 / 이벤트에 / 참여하세요 / !
    ↓
단어 ID 변환
    ↓
Embedding
    ↓
CNN 특징 추출
    ↓
정상 또는 피싱·광고 분류
```

단어의 연속적인 조합에서 특징을 추출하여 피싱 및 광고 문장을 탐지하는 데 사용합니다.

### 6-3. 두 모델의 차이

| 구분 | Char-CNN | TextCNN |
|---|---|---|
| 입력 단위 | 문자 | 단어 및 기호 |
| Embedding 차원 | 64 | 128 |
| CNN Kernel Size | 3, 4, 5 | 2, 3, 4 |
| 최대 입력 길이 | 300 | 128 |
| 탐지 대상 | 유해 표현 | 피싱·광고 |

두 모델은 각각 독립적으로 문장을 분석하며, 최종 결과는 두 모델의 예측 결과를 조합하여 결정합니다.

## 7. 모델 학습 방법

모델 학습은 `train.ipynb`에서 진행합니다.

### 7-1. 데이터 분리

데이터를 학습, 검증, 테스트 용도로 나눕니다.

| 데이터 | 비율 | 용도 |
|---|---:|---|
| 학습 데이터 | 64% | 모델 학습 |
| 검증 데이터 | 16% | 학습 중 성능 확인 |
| 테스트 데이터 | 20% | 최종 모델 성능 평가 |

### 7-2. 학습 설정

| 항목 | 설정 |
|---|---:|
| Batch Size | 64 |
| 최대 Epoch | 50 |
| Learning Rate | 0.001 |
| Dropout | 0.3 |
| Early Stopping | 5 |

### 7-3. 과적합 관리

학습 데이터에 지나치게 맞춰지는 현상을 줄이기 위해 다음 방법을 적용합니다.

- **Dropout:** 학습 중 일부 뉴런을 무작위로 비활성화합니다.
- **Early Stopping:** 검증 데이터의 F1-score가 일정 횟수 동안 개선되지 않으면 학습을 중단합니다.
- **최적 모델 저장:** 검증 F1-score가 가장 높았던 시점의 모델 가중치를 저장합니다.

### 7-4. 모델 평가

학습이 끝난 후 테스트 데이터를 이용하여 모델 성능을 확인합니다.

주요 평가지표는 다음과 같습니다.

- Accuracy: 전체 예측 중 정답을 맞힌 비율
- Precision: 탐지 대상으로 예측한 데이터 중 실제 탐지 대상의 비율
- Recall: 실제 탐지 대상 중 모델이 찾아낸 비율
- F1-score: Precision과 Recall을 종합한 지표

## 8. 실행 방법

### 8-1. 개발 환경 준비

Python이 설치된 환경에서 프로젝트를 실행합니다.

필요한 주요 라이브러리는 다음과 같습니다.

```bash
pip install pandas numpy scikit-learn torch streamlit plotly
```

Jupyter Notebook을 사용하려면 다음 라이브러리도 설치합니다.

```bash
pip install notebook
```

※ 라이브러리 버전은 별도의 고정 설정이 제공되지 않았으므로, 실행 환경에 따라 호환성 확인이 필요합니다.

### 8-2. 모델 학습

Jupyter Notebook을 실행합니다.

```bash
jupyter notebook
```

브라우저에서 `train.ipynb` 파일을 열고 위에서부터 순서대로 셀을 실행합니다.

학습이 완료되면 모델 가중치와 어휘 사전 등의 파일이 저장됩니다.

### 8-3. Streamlit 실행

학습된 모델 파일이 준비되어 있는지 확인한 후 터미널에서 다음 명령어를 실행합니다.

```bash
streamlit run app.py
```

실행하면 브라우저에서 웹 애플리케이션에 접속할 수 있습니다.

※ `app.py`에서 지정한 모델 폴더와 학습 노트북의 모델 저장 폴더가 일치해야 합니다. 현재 코드의 경로 설정은 서로 다를 수 있으므로 실행 전에 확인해야 합니다.

## 9. 사용 방법

1. Streamlit 웹 애플리케이션을 실행합니다.
2. 실시간 탐지 화면으로 이동합니다.
3. 분석할 문장을 입력합니다.
4. 분석 버튼을 클릭합니다.
5. Char-CNN과 TextCNN의 예측 결과를 확인합니다.

### 최종 판정 기준

| Char-CNN 결과 | TextCNN 결과 | 최종 판정 |
|---|---|---|
| 정상 | 정상 | 정상 |
| 유해 표현 | 정상 | 유해 표현 |
| 정상 | 피싱·광고 | 피싱·광고 |
| 유해 표현 | 피싱·광고 | 유해 표현 + 피싱·광고 |

## 10. 프로젝트의 한계 및 향후 개선 방향

### 한계점

- CNN 모델은 문자나 단어의 연속적인 패턴을 학습하는 방식이므로 문장 전체의 맥락과 의도를 이해하는 데 한계가 있습니다.
- 학습 데이터에 포함되지 않은 새로운 유해 표현이나 피싱 문장은 정확하게 탐지하지 못할 수 있습니다.
- 정상 문장을 유해 문장으로 판단하거나, 탐지 대상 문장을 정상으로 판단하는 오탐지 및 미탐지가 발생할 수 있습니다.
- 현재는 유해 표현과 피싱·광고라는 두 가지 탐지 유형을 중심으로 구성되어 있습니다.

본 프로젝트에서는 서로 다른 탐지 목적에 맞춰 Char-CNN과 TextCNN을 각각 학습하고, 두 모델의 결과를 결합하는 문장 탐지 시스템을 구현했습니다.

데이터 전처리부터 모델 학습, 성능 평가, 모델 저장 및 Streamlit을 이용한 웹 애플리케이션 구현까지의 과정을 경험했습니다.

특히 모델을 학습하는 과정뿐 아니라 학습된 모델을 실제 서비스 화면과 연결하고, 사용자가 입력한 문장을 분석할 수 있도록 구성하는 과정을 통해 머신러닝 및 딥러닝 모델의 활용 흐름을 이해할 수 있었습니다.
